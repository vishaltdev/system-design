04 / CHECK THE ORDER OF MAGNITUDE

Turn a workload into a capacity conversation.

Average QPS = users × requests ÷ 86,400. Peak QPS = average × multiplier. Logical storage = daily requests × write share × bytes × retention. Decimal GB/TB; excludes replicas, indexes, compression, updates, deletions and compaction.

This is request and logical-storage arithmetic. It does not predict server count, database capacity or network egress. Measure service time, read payload sizes, fanout, skew and resource headroom before sizing infrastructure.
